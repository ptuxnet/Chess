 # ♟️ Flutter Chess App

A modern and interactive chess application built with **Flutter**.  
Play classic chess on a beautifully designed board with smooth animations, rule validation, and customizable themes.

---

## 🚀 Features

- 🏁 Interactive **8×8 chessboard** with alternating square colors  
- ♟️ **Piece movement & validation** (only legal moves allowed)  
- 👥 **Player vs Player (local)** mode  
- 🔄 Move **history tracking**  
- 📱 **Responsive design** – works perfectly on all screen sizes  

---

## 🛠️ Tech Stack

- **Framework:** Flutter (Dart)  
- **State Management:** Riverpod  
- **UI:** Material Design, Custom Widgets  
- **Logic:** Custom chess engine for move legality and checkmate detection  

 
---

## 💡How It Works

- Each square is dynamically colored based on its position.  
- Pieces follow valid chess movement rules.  
- The app detects turns, captures, and check/checkmate states (if implemented).
